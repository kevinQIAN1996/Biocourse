## 平台 v4.0 · 2026-10-28

22 个主题，29 个课件版本，包含 7 份 WorkBuddy 课件。首页按必修 1、必修 2、选择性必修 2 分类。各主题有独立 SVG 封面，每版都有独立课堂页面、概述、功能、讲授思路、版本记录和主题反馈。

- `catalog.json`：完整主题及版本注册表；`courses.json`：平面文件清单。
- `courses/<主题>/<版本>/index.html`：独立版本页面，内嵌原课件。
- 原有 HTML 文件保留在原路径；导入课件放在 `workbuddy/`，仅包含 7 份课堂 HTML，没有上传 `.workbuddy` 记忆或其他文件。
- 旧版直达页面增加隔离样式的返回按钮；内嵌时使用外层常驻导航。
- 本站公开日期依据首次上线记录，导入日期为本次上线日期，不等于源文件创作日期。
- WorkBuddy 同主题版本标为 2.0；新增主题为 1.0；ATP 修正整体水解释能表述后为 2.0.1。原文件在本机仍保留，网站原版也保持可用。
- 完整功能与讲授说明见 `版本与教学指南.md`。

## 打开次数与评论

统计使用第三方不蒜子公共服务。每个原课件路径是独立统计键，实际载入（包括 iframe、直达和刷新）记录一次；目录与版本列表只读 GET，不增加次数。新统计不能补算之前的历史。无服务可用性或人数精度保证，网络错误显示“—”。第三方会收到访问地址和网络信息。首页保留独立 PV/UV 估算和北京时间。

评论使用 GitHub Issues 公共 API，浏览器无需密钥即可读取。发言在 GitHub 确认，需 GitHub 账号；主题标记为 `[BC:主题ID]`，同主题版本共享讨论，正文注明具体版本。页面自动展示最近 6 条相关讨论与每条前 10 个回复；其余通过完整讨论链接查看。API 限流或网络错误会明确提示，不能当作“没有留言”。不会自动发布任何留言。

## v4.1 · 教材章节与版本 UV/PV

按人教版教材的模块—章—节组织已上线课件，定位菜单支持大章和小节。跨小节或全章课件显式列出覆盖范围。目录数据见 curriculum.json；主题映射见 catalog.json 的 curriculum 字段。仅列出已有资源，不表示完整教材已全部制作。

课程卡片、独立版本页和历史版本栏同时显示打开人数（UV 估算）和打开次数（PV）。UV 不是精确自然人数或在线人数，不能简单跨版本相加；目录 GET 查询不增加次数。POST 载入事件同时同步 UV、PV，保留原有统计键及累计数据。

目录核对参考：已有配套教材图片及国家智慧教育平台人教版课程章节目录 https://v1.ykt.cbern.com.cn/65/document/1e3b7fe7535a4cb4a8ab1f903f802247/pdf.pdf ，教育部精品课目录 https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A06/202203/W020220318610109798820.pdf 。
