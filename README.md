# Biocourse
主要是我自己开发的一些HTML课件资源

## 在线课件

网站：[BioCourse · 高中生物互动课件](https://kevinqian1996.github.io/Biocourse/)

目录提供主题搜索、分类筛选、在线打开与 HTML 下载。目前公开4份课件：

- 蛋白质生命架构实验室
- 核酸训练实验室
- 细胞膜 · 边界研究所
- 细胞器图鉴 · 2D互动版

课件以独立 HTML 文件发布，下载后可以使用现代浏览器打开。网页目录使用本地搜索，不收集学生信息。引用课件内的图片或教学材料时，请遵循原作者许可和课件内的署名说明。

GitHub Pages 从 main 分支根目录发布。更新课件或 index.html 并提交后，网站会自动重新发布。
