# Biocourse
主要是我自己开发的一些HTML课件资源

## 在线课件

网站：[BioCourse · 高中生物互动课件](https://kevinqian1996.github.io/Biocourse/)

目录提供主题搜索、分类筛选、在线打开与公开留言。目前公开4份课件：

- 蛋白质生命架构实验室
- 核酸训练实验室
- 细胞膜 · 边界研究所
- 细胞器图鉴 · 2D互动版

课件可以在线使用，目录已移除下载按钮。搜索在本地运行；首页接入不蒜子第三方访问统计（首页 UV 估算及 PV，不包含独立课件页面），第三方会处理访问记录并可能保存本地访客标识。时间使用设备时钟换算为北京时间。反馈通过 GitHub Issues 公开提交，需要 GitHub 账号。引用课件内的图片或教学材料时，请遵循原作者许可和课件内的署名说明。

GitHub Pages 从 main 分支根目录发布。更新课件或 index.html 并提交后，网站会自动重新发布。

## 界面 v2.0（2026-10-28）

采用深蓝科学展览封面、响应式课件卡片、搜索筛选、北京时间、访问统计与反馈表单。近期留言按需读取 GitHub 公共 API；网络错误或限流时保留直接访问反馈区的入口。统计服务无可用性保证，不用于计费。隐藏下载按钮不构成访问控制，公开 HTML 及公开仓库仍可获取源文件。

## v3.0：完整课件目录与社群

公开 22 份独立 HTML：20 份主题课件与 2 份历史版本。课程目录按照必修 1、必修 2、选择性必修 2 分类；游戏工程和工具项目不属于本次发布。资源清单见 courses.json。

### 更新微信群二维码
1. 用新的原始二维码图片替换 assets/wechat-group.png（保留名称，勿压缩或裁掉二维码边缘）。
2. 修改 community-config.js 中的 expiresAt（北京时间）、validityText 和 version（例如日期），保存并提交。
3. GitHub Pages 自动部署后访问网站社群区域检查。页面到有效期会自动隐藏过期二维码。微信可能提前使二维码失效，实际能否入群以微信为准。

旧版文件仍保留，默认目录展示 20 份，点击“历史版本”查看其余 2 份。
