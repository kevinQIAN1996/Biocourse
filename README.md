## 平台 v4.0 · 2026-10-28

22 个主题，29 个课件版本，包含 7 份 WorkBuddy 课件。首页按必修 1、必修 2、选择性必修 2 分类。各主题有独立 SVG 封面，每版都有独立课堂页面、概述、功能、讲授思路、版本记录和主题反馈。

- `catalog.json`：完整主题及版本注册表；`courses.json`：平面文件清单。
- `courses/<主题>/<版本>/index.html`：独立版本页面，内嵌原课件。
- 原有 HTML 文件保留在原路径；导入课件放在 `workbuddy/`，仅包含 7 份课堂 HTML，没有上传 `.workbuddy` 记忆或其他文件。
- 旧版直达页面增加隔离样式的返回按钮；内嵌时使用外层常驻导航。
- 本站公开日期依据首次上线记录，导入日期为本次上线日期，不等于源文件创作日期。
- WorkBuddy 同主题版本标为 2.0；新增主题为 1.0；ATP 修正整体水解释能表述后为 2.0.1。原文件在本机仍保留，网站原版也保持可用。
- 完整功能与讲授说明见 `版本与教学指南.md`。

## 打开次数与评论

统计使用第三方不蒜子公共服务。每个原课件路径是独立统计键，实际载入（包括 iframe、直达和刷新）记录一次；目录与版本列表只读 GET，不增加次数。新统计不能补算之前的历史。无服务可用性或人数精度保证，网络错误显示“—”。第三方会收到访问地址和网络信息。首页保留独立 PV/UV 估算和北京时间。

默认在站内免登录提交，昵称选填；提交后返回持久保存回执。反馈接收服务通过独立的 GitHub Actions 工作流定期归档到 [BioCourse-feedback](https://github.com/kevinQIAN1996/BioCourse-feedback/issues)，归档可能延迟。主题标记为 `[BC:主题ID]`，同主题版本共享讨论，正文记录具体版本、页面、反馈类别和原文。科学纠错标记 `science-review`，均先待核查，避免自动采纳未经验证的结论。

浏览器通过 GitHub Issues 公共 API 读取最近 6 条相关讨论与每条前 10 个回复；网络或限流失败明确提示。也保留登录 GitHub 直接提交及回复的可选入口。匿名提交内容将公开归档，请勿填写学生身份或其他敏感信息。前端不包含 GitHub 密钥；同步只使用短期工作流令牌和受校验的 GitHub OIDC 身份。网站 Star 按钮仅打开主项目仓库，由访客自行登录后点 Star。
