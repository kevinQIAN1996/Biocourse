你的预测：相对基线怎样变？

小信号，大效应；作用后需清除

信号放大、体液运输、靶向作用、作用后灭活清除，共同构成激素调节的特点。

“起作用后被灭活”用于强调激素需不断合成和分泌。真实清除有时间过程和多种途径，不是每个分子一碰受体便瞬间被剪断；本图以 TSH 的受体介导内吞/降解作简化示意。

高考激素调节过程 · 满分法典

01 / 血糖三来三去

三来三去
食物中糖类消化吸收（主要来源）氧化分解供能（主要去路）
肝糖原分解合成肝糖原、肌糖原
非糖物质转化转变为脂肪等非糖物质

胰岛素促三去、抑二来；胰高血糖素主要促肝糖原分解与糖异生。肌糖原不能直接释放葡萄糖补充血糖。肌肉产生的乳酸等可经肝脏间接参与糖异生，不要把“不能直接”误读为完全没有代谢联系。

03 / 受体、囊泡与糖尿病

胰岛素 → 膜受体 → 胞内信号 → GLUT-4 囊泡转位并融合 → 膜上载体增加 → 摄糖增强。GLUT-4 转运葡萄糖属于协助扩散；含它的囊泡运输与融合需能量。

1 型主要是胰岛素绝对缺乏；2 型主要涉及抵抗和随病程变化的分泌障碍。多尿的链条是尿中葡萄糖增多 → 肾小管液渗透压升高 → 水重吸收受阻 → 渗透性利尿；不能直接归因于缺 ADH。

04 / 协同与相抗衡

激素组合共同或相反的生理效应
生长激素 + 甲状腺激素在促进生长发育方面协同
甲状腺激素 + 肾上腺素在增加产热等方面协同
胰高血糖素 + 肾上腺素 + 糖皮质激素在升血糖方面协同，时程与机制不同
胰岛素 vs 胰高血糖素在血糖调节方面相抗衡
TRH vs TH 对 TSH 分泌的作用TRH 促进，TH 抑制：作用方向相反

05 / 激素“五不做”

  • 不以结构材料的身份发挥作用。
  • 不以供能物质的身份发挥作用。
  • 不充当酶直接催化代谢反应。
  • 不只朝某一个器官定向运输。
  • 不对每一个流经的细胞都产生同样效应，需匹配受体与响应系统。
答题因果模板：刺激变化 → 相应分泌细胞响应 → 激素经体液运输 → 特异性受体识别 → 靶细胞代谢改变 → 指标恢复，并通过负反馈防止过度调节。
