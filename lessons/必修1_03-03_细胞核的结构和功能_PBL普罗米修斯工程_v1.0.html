结构底账

核膜由内、外两层生物膜组成；每层膜是磷脂双分子层，共有4层磷脂分子。经核孔的这条通路并不穿过磷脂双分子层。

为什么不写“一律消耗ATP”？

01 / 四份经典证据，分别回答什么？

实验改变与观察对照与结论边界
美西螈核移植黑色个体的胚胎细胞核，进入白色个体的去核卵；教材情境中发育个体呈黑色。支持肤色遗传受核内遗传物质控制；补做反向核移植，有助于完善相互对照。不能据此说细胞质毫无作用。
蝾螈受精卵横缢含核部分继续分裂，无核部分停止；后来获得核的部分也能分裂。有核、无核形成相互对照；同一部分获得核前后形成自身对照。
变形虫切割与植核无核部分生命活动逐渐受损；及时植核可恢复相应活动。支持核与生命活动的关系；正常活动还依赖完整的细胞结构和核质协调。
伞藻嫁接与核移植假根含核，也含少量细胞质；嫁接后观察帽形，再补做核移植与适当对照。嫁接不能单独排除假根细胞质影响。核移植提供进一步区分核、质效应的证据，不等于绝对不带入任何细胞质。

02 / 核孔通行：来源 → 去向 → 层数

本轮情境典型路线判定
核内工作的聚合酶、解旋酶、组蛋白细胞质核糖体合成蛋白质 → 输入核内核孔运输，跨磷脂双分子层数为0
新形成的mRNA、tRNA、核糖体亚基核内形成或预装配 → 输出到细胞质有选择性；不能概括成所有RNA永不回核
核DNA正常核膜完整的细胞中，不作为核孔外运货物核移植实验搬运细胞核，并非DNA经核孔外流

两层生物膜＝四层磷脂分子；经核孔走通道不等于穿过膜的脂质双层。多种定向运输需要能量，但不同途径的分子机制不同。

03 / 核仁不是一个“造蛋白质的反应堆”

核仁没有膜包被，与某些rRNA的合成、加工和核糖体亚基的预装配有关。核糖体蛋白在细胞质中合成后输入核内；亚基输出后还有后续成熟。并非所有rRNA都在核仁中转录。相近条件下，合成活跃程度与核仁大小、核孔数量常有关联，不能机械理解为普遍线性关系。

Cooper：核仁与核糖体生物发生 ↗核仁结构、功能与组装研究综述 ↗

04 / 一句话，必须说准

  • 细胞核是遗传信息库，是细胞代谢和遗传的控制中心；不是把全部代谢反应都放在核内进行。
  • 细胞质基质及细胞器承担多种代谢活动；真核细胞也可含细胞器DNA。
  • 染色质与染色体主要成分相同，是同种物质在不同时期的两种存在状态。
  • 本页折叠模型比较G2与分裂前期：DNA已复制，包装变化期间始终是1条染色体、2个DNA分子。
  • “碱性染料”不等同于“溶液一定呈碱性”。
染色体染色与碱性染料结构研究 ↗

05 / 三个需要带条件的特例

  • 大肠杆菌等原核细胞：没有核膜、核仁，仍有DNA与核糖体。
  • 哺乳动物成熟红细胞：没有细胞核，不能据此否定一般真核细胞的核质协调。
  • 高等植物成熟筛管分子：没有细胞核，其正常生理活动与伴胞支持密切相关。
