01 / 光合不一定有叶绿体

典型颤蓝细菌 vs 水绵；光合膜与线粒体用示意伪彩标出。

光合膜 / 叶绿体线粒体核膜包被的细胞核

颤蓝细菌 · 原核

无叶绿体，有藻蓝素、叶绿素a与光合片层。

无线粒体，也可含有氧呼吸所需的酶。

水绵 · 真核

有螺旋带状叶绿体、线粒体和细胞核。

结构不同，也能进行光合作用与呼吸作用。

证据判断：蓝细菌能进行光合作用，能否反推它有叶绿体？

把“一个细胞器”与“完成反应的结构、色素及酶”分开想。

02 / 抗生素在找什么靶点？

选定菌株的机制模型，不用于判断个体病情或给出用药方案。

左：对本模型β内酰胺敏感的大肠杆菌。右：没有细胞壁的支原体。选择药物，观察靶点是否存在。
β内酰胺类（含青霉素、头孢类）针对肽聚糖细胞壁合成；支原体没有这个靶点。阿奇霉素作用于核糖体，抑制蛋白质合成，不是“阻止核糖体合成”。具体药物是否有效还受敏感性等影响。

支原体不怕β内酰胺类，最直接的证据是？

没有靶点的天然不敏感，与对另一类药物产生耐药，机制并不相同。

≠
真正可迁移的解释：先找结构，再说功能。

支原体仍然有细胞膜、DNA和核糖体，是已知体积很小、可自主复制的细胞生物之一。“无壁”不等于“无膜”，“无核”指无核膜包被的细胞核。

显微镜：移中 → 转换 → 调光 → 细调

物像偏哪，玻片往哪移。物镜与目镜放大倍数相乘；换高倍后视野小、细胞大，通常需要调亮并用细准焦。

放大倍数变 n 倍：一行计数约÷n，均匀铺满视野约÷n²。分清“长度”和“面积”。

名字迷惑术：菌 ≠ 都是细菌

发菜、颤蓝细菌：原核；衣藻、黑藻：真核。乳酸菌：原核；酵母菌：真核真菌。T2噬菌体：病毒，无细胞结构。

“颤念色发是蓝菌”可帮助记忆常见旧名，但命名不是分类证据，核膜与结构才是。

“一藻二菌三体”怎么用？

常用旧口诀：蓝藻（蓝细菌）；细菌、放线菌；支原体、衣原体、立克次氏体。均属常见原核生物学习名单。

它不是分类阶元表：放线菌和这“三体”本身也属于细菌；不是完整的原核生物分类。

别把“没有细胞器”说顺嘴了

原核细胞有核糖体。无核膜包被的细胞核，不等于没有DNA。蓝细菌无叶绿体可光合；无线粒体可有氧呼吸。

真核染色体典型地由DNA与蛋白质构成；原核有拟核DNA，在现代术语中也可称细菌染色体，不宜笼统说“没有任何染色体”。

特殊细胞：先交代适用范围

对象辨析证据
哺乳动物成熟红细胞失去细胞核和细胞器；仍有膜、细胞质并以糖酵解供ATP。真核来源。
植物成熟筛管分子无细胞核，但仍保留部分细胞器，并由伴胞支持；不能说“无一切细胞器”。
酵母菌 / 莱茵衣藻前者是真菌，无叶绿体；后者有叶绿体，细胞壁主要为糖蛋白。
支原体 / T2噬菌体前者有细胞结构、无壁；后者无细胞结构，不属于原核细胞。
